Sistema web institucional orientado a centralizar la información de productos, proveedores, categorías y movimientos internos. La plataforma permite consultar y administrar recursos de oficina, pedagógicos y de aseo mediante una API REST desarrollada con Django y Django REST Framework.

Objetivo de la plataforma

Inventario Central permite digitalizar el registro de materiales del CEIA La Pintana, centralizar la información y apoyar la toma de decisiones sobre el uso de recursos internos. Su API REST permite consultar, crear, actualizar y eliminar registros de forma estructurada, favoreciendo una gestión más ordenada y escalable.
